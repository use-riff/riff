# Security

riff's programs hold user funds and are an unaudited beta. If you find a vulnerability, please
report it privately and don't open a public issue:

- **GitHub:** Security tab → "Report a vulnerability" on this repository.
- **X:** a direct message to [@useRiffPad](https://x.com/useRiffPad) asking
  for a secure contact.

Include what you found, how to reproduce it, and the impact you expect. We'll
acknowledge reports as soon as we can and keep you updated while we fix it. We don't promise a response time.

There is currently no bug bounty, but we welcome reports. Please don't access other people's funds or data, or test on mainnet beyond what you need to show the problem.

In scope: the programs in `programs/riff-dbc/` and `programs/riff-passport/`, deployed at the addresses in
`deployments.json`. The app and other off-chain services aren't in this
repository.
